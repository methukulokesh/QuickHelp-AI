# Daily Progress – 13 November 2026

## Project
QuickHelp AI – AI assistant chatbot system

## Work completed in this MVP build
- Created a Streamlit chat interface with selectable Ollama/OpenAI providers.
- Added document upload and text extraction for PDF, DOCX, TXT, and Markdown.
- Implemented chunking and TF-IDF/cosine-similarity retrieval for uploaded documents.
- Added SQLite persistence for conversation history and a clear-history action.
- Added a restricted AST-based arithmetic tool.
- Added setup instructions, architecture overview, environment template, and unit tests.

## Validation
- Run `python -m unittest discover -s tests -v`.
- Install requirements and run `streamlit run app.py`.
- Live LLM responses require a working local Ollama model or a valid OpenAI API key.
